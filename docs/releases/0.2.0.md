Clicky 0.2.0 (build 6) adds authentic press and release sounds for ten keyboard packs and Razer Orochi V2 mouse clicks, alongside the existing sounds.

## What changed

- Twenty keyboard profiles in total. The ten new tplai packs include separate releases and distinct Space, Enter, and Backspace recordings.
- Razer Orochi V2 has separate left/right button-down and button-up recordings. Middle click uses the left-button pair.
- Releases play when the physical key or mouse button comes up. Held keys, repeat events, and orphan releases do not create extra hits.
- Recorded releases play about 3 dB softer (70% gain), including complete previews with a 100 ms hold. Press levels and custom imports keep their configured volume.
- Matching keyboard and mouse playback in the website playground, plus Cloudflare Workers deployment tooling.

## Install

Download **Clicky-macOS-arm64.zip**, unzip it, move **Clicky.app** to Applications, and open it. Requires **Apple Silicon and macOS 13 or later**. Enable Clicky in **System Settings → Privacy & Security → Input Monitoring**, then quit and reopen if macOS asks.

This build uses the existing local development signing certificate and is **not Apple-notarized**. The ZIP includes `INSTALL.txt` with first-launch instructions. The app signature was verified after extracting the ZIP.
