FEELS RIGHT AT HOME

Made for Mac.
Made to stay yours.

Built natively with Swift. Clicky runs offline and listens for physical key presses to play your sounds. It never reconstructs or stores what you type.

Mac app available from source
Windows is on the roadmap
Opening Clicky for the first time +

The current release is locally signed and has not been notarized by Apple. After downloading and opening Clicky, macOS may ask you to allow it in System Settings → Privacy & Security → Open Anyway.

Enable Input Monitoring for Clicky, then quit and reopen the app. This lets Clicky hear physical key presses while you work in other apps.
